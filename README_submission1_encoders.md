# HerWILL Safe Social Media Datathon 2026

3-class harmful-content classification for Bangla, English and Banglish social-media text
(0 = explicitly toxic, 1 = subtly toxic, 2 = neutral). The metric is macro F1.

**Final model (code submission):** a soft vote of Qwen3-4B-Base + LoRA (weight 0.50), XLM-RoBERTa-XL + LoRA (0.25)
and a word+char TF-IDF logistic regression (0.25), all trained with the same 5-fold stratified CV.
5-fold OOF macro-F1 is 0.6165. The single reproducible notebook is `kaggle_final/herwill_final_kaggle.ipynb`;
see `kaggle_final/README.md` for how to run it on Kaggle.

## How to run Submission #1

**Kaggle notebook** (on a T4, set `FORCE_FP16=1`: with torch 2.3 or newer, `torch.cuda.is_bf16_supported()` also
returns True on a T4 through slow emulation)
1. Upload `notebooks/herwill_final.ipynb` (or paste `src/herwill_final.py`) into a notebook attached to the competition data.
2. Settings: Accelerator **GPU T4** and Internet **On**, so the pretrained weights can be downloaded from the Hugging Face Hub.
3. Run all cells. The notebook finds the data under `/kaggle/input/` and writes `submission.csv` to `/kaggle/working/`.
   * Expected runtime on a T4 is about 6 h for 5 folds. Set `FOLDS=3` (environment variable, or edit `CFG`) to roughly halve it.
   * Every (model, fold) result is cached in `cache/`, so a restarted session resumes where it stopped.

**Local GPU**
```bash
python -m venv .venv && .venv/bin/pip install -r requirements.txt
.venv/bin/python src/herwill_final.py            # full run, about 1.5 h on an RTX 4090
QUICK=1 .venv/bin/python src/herwill_final.py    # 2-minute smoke test on a subset
```

## Key findings from the analysis (`experiments/logs/`)

| Finding | Evidence | Decision |
|---|---|---|
| Neutral is the minority class (12.3%) | 49.7 / 38.0 / 12.3 split | Class-weighted CE, weights (N/n_c)^0.5 |
| 58% Latin script, 41% Bangla, 2% mixed | script detection | Multilingual encoders |
| Train and test are identically distributed | KS on length p=0.15, same script mix | Random stratified K-fold is a valid proxy |
| Short texts | median 8 words, token p99 about 90-113 | max_len 128 |
| Some label noise | 63 identical texts with conflicting labels | Kept as is (<0.4% of rows) |
| `id` leaks label (row order of the source corpora) | neighbour-id labels alone reach macro F1 0.593 | **Never used.** It would be exploiting a data artifact |
| Ensemble beats the best single model | +0.018 macro F1, paired-bootstrap 95% CI [+0.010, +0.026] | 4-model soft vote |
| Class-threshold tuning does not generalise | split-half held-out gain −0.003 | Not used |

| mDeBERTa-v3 base | 0.572 | 0.692 | 0.514 | 0.509 | 0.601 | 0.482 |

Kaggle public leaderboard: **0.5912** (CV 0.5936, a gap of −0.002, which is inside public-split noise).
Total training time is 102 min on one RTX 4090.

Experiments tried and rejected (fold 0, see `experiments/logs/06`–`09`):
* Adding BanglaBERT to the ensemble: +0.001 to +0.002, not significant. Also excluded for its non-commercial license.
* Exact-duplicate label lookup, and TF-IDF kNN label features with stacking: +0.000 to +0.001, not significant. LR stacking scored 3 points below plain averaging.
* XLM-R large with label smoothing 0.1, LLRD 0.92 and FGM (2 seeds): single model +0.6 (0.585 vs 0.579), but the ensemble gain is at most +0.003 and not significant, while training time doubles.

## Rule compliance
* Only the competition data is used. There is no external, scraped or pseudo-labelled data, and no checkpoints fine-tuned on toxicity or sentiment labels.
* Pretrained models are plain self-supervised encoders with OSI-approved licenses that permit commercial use.
* The `id` column is not used anywhere in the model.
* Deterministic folds and fixed seeds; all hyper-parameters are listed in `CFG` at the top of the script.
* The dataset must not be shared outside the competition, so `data/` must not be published with this code.
